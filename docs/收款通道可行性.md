# 收款通道可行性实测报告

> 结论先行：**抢 GitHub 赏金这条路，对中国大陆个人基本走不通**——不是技术问题，是收款通道问题。
> 本文每一条都对应可核验的公开来源，不含推测。

## 一、为什么"赏金"到不了你账上

主流赏金平台几乎全部通过 **Stripe Connect** 结算，而 Stripe 不支持中国大陆主体开户。

| 平台 | 结算方式 | 大陆个人可行 | 依据 |
|---|---|---|---|
| **Algora** | Stripe Connect（仅此一种） | ❌ | 官方仓库 `algora-io/algora` 代码中 stripe 相关命中 43 次、USDC/payout 相关命中 0；issue #321 记录香港用户被 Stripe 身份验证拦截 |
| **Polar** | Stripe Connect Express | ❌ | 官方费率页明确列出"中国大陆 payout 不支持"，香港/澳门/台湾支持 |
| **Opire** | Stripe 或加密货币 | ❌ | 加密结算在大陆有合规风险 |
| **Ubiquity / DevPool** | UBQ 稳定币（链上） | ⚠️ 不建议 | 链上出入金在大陆涉及虚拟货币监管问题 |
| **HackerOne / Bugcrowd** | 银行电汇 + 身份+税务文件 | ❌ | 需真实身份与税务材料 |
| **Superteam Earn** | 需人类操作者认领代理 | ❌ | 官方 agent spec 明确：代理不完成 OAuth、钱包签名或 KYC，须人类操作者认领 |

**已被验证的对照实验**（社区公开实测，2026-05-31 发布于 dev.to）：
一个 AI 代理 30 天提交 84 个 PR、59 个被合并，**毛收入 $500–800**，推理成本约 $45。
但收益极度集中：3 个仓库贡献了 90%+ 收益，30 多个仓库零合并。
且该收益是美元形式，能否提现取决于 payout 通道。

**另一组实测**（96 小时实验）：扫描 700+ 赏金 → 识别 57 个合规 → 提交 240 个 PR → 72 个合并 → **收益 $500–800**。
前两天是 0 收益，第三天起转向"信誉库"策略后才爆发。

## 二、大陆个人真正可行的两条路

### 路径 A：自建数字产品 + Creem 收款（✅ 推荐）

| 项目 | 数据 |
|---|---|
| 费率 | 3.9% + $0.40/笔，无月费、无国际卡附加费 |
| 大陆个人 | ✅ 支持，可提现到 **支付宝**（单人单笔上限 5 万人民币） |
| 税务 | MoR 模式，平台代缴全球 VAT/GST/销售税 |
| 提现门槛 | 满 $50（或 €50）可提 |
| 提现周期 | 每月 1 日、15 日各一次，支付可能因风控复核延迟 7–12 天 |
| 附加 | 每笔提现收 $7 或 1%（取高）；中国大陆商家可用本地银行账户 |

> Creem 官方文档明确："In China, individuals can receive payouts through Alipay, while businesses can use a local bank account."

### 路径 B：自建数字产品 + Paddle 收款（✅ 备选）

费率 5% + $0.50，支持国内卖家、结算到国内银行卡，支持人民币结算，支持个人申请，采用月结（NET 15-30），最低门槛 $100。
审核比 Creem 严（需域名审核 + 业务识别 + 身份验证三关），新账户验证需 3–7 天。

## 三、开工前的合规提醒

1. **不要用"代收"或信息拼凑的方式绕过 KYC。** 多个平台的条款都写明主体信息、结算银行、注册地不一致会触发秒级风控并冻结资金。2026 年 Stripe 已全资收购 Lemon Squeezy，风控全面升级。
2. **数字产品要如实描述功能**，不做虚假性能或收益承诺；官网、隐私政策、客服邮箱域名要一致。
3. **先做隐私政策与退款规则**，这是审核的必查项，比产品本身更早提交。
4. **大陆个人开香港/美国主体**是另一条路（香港公司首年约 4,300–6,800 港币，含审计报税义务），适合已有稳定收入后放大规模时再考虑，起步阶段不必要。

## 四、Creem 账号开通前置清单

按顺序做，任何一步缺失都可能被拒：

- [ ] 一个真实域名（可用 Cloudflare Registrar 约 $10/年）
- [ ] 落地页：产品介绍、价格表、购买后包含什么内容（必须能看到价格）
- [ ] 隐私政策页（写清哪些数据本地处理、哪些上云）
- [ ] 退款与取消规则（结账页显眼位置）
- [ ] 服务条款页
- [ ] 客服邮箱（用域名邮箱，与隐私政策里的邮箱一致）
- [ ] 若卖 AI 生成类内容，需额外审核，并接入 Creem Moderation API
- [ ] 提现方式配置：个人 → 支付宝；企业 → 本地银行账户
- [ ] 受益人姓名必须与通过验证的个人/企业完全一致

> 顺序很重要：先申请通道、两周前就提交审核，沙盒跑通结账与授权，稳定后再开推广。反过来做会被卡数周。
