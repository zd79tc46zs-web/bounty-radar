# 挂机收益系统

> 用 GitHub 做自动化副业的完整可运行方案。**已实测跑通**，不是纸上谈兵。

## 核心结论（先看这个，能省你几天时间）

**"抢 GitHub 赏金自动赚钱"这条路，对中国大陆个人走不通** —— 不是技术问题，是收款问题。

- Algora / Polar 全部走 **Stripe Connect**，而 Stripe 不支持中国大陆主体开户。
  官方仓库代码可证：Algora 有 43 处 stripe 引用、0 处 USDC 引用；
  官方 issue #321 记录了香港用户被 Stripe 身份验证拦截的真实案例。
- Ubiquity/DevPool 用 UBQ 稳定币结算，链上出入金在大陆有合规风险。
- 社区实测：AI 代理 30 天提交 84 个 PR、59 个被合并，毛收益 $500–800，
  但收益集中在 3 个仓库，且**纯自动提 PR 会被判为机器人、毁账号信誉**。

**真正能收到钱的路径**：自建数字产品 + **Creem** 收款（支持大陆个人、提现到支付宝、MoR 代缴全球税）。

所以本项目做成**两条腿**：
- 腿一（信息）：赏金雷达，把"钱在哪、哪些是假的、哪些大陆能收"全自动查清楚
- 腿二（收钱）：数字产品自动生成与上架，走能提现到支付宝的通道

### 反作弊判据（实测得出，非猜测）

三个假仓库的共同指纹，与真实付款仓库对比：

| 仓库 | 真人合并PR | 贡献者 | 关注者 | 真实付款 |
|---|---|---|---|---|
| warpspeed-bounties（挂 $660） | **0** | 1 | 0 | ❌ 从未付过 |
| bounty-plaza（挂 $750） | **0** | 1 | 0 | ❌ 198 个关闭 issue 全是刷量 |
| awesome-agent-bounties（挂 $3k） | **0** | 1 | 0 | ❌ |
| ubiquity/business-development | 20 | 8 | 2 | ✅ |

> 关键教训：`closed_bounties`（已关闭赏金数）**单独用会失效** —— bot 农场批量关 issue 让它虚高到 198。
> 硬判据是 **真人合并 PR 数**。

## 目录结构

```
github-earning/
├── radar/
│   ├── scan.py              # 扫描器：抓赏金 + 反作弊 + 通道判定 + 评分
│   └── hunter.py            # 执行器：认领 / 克隆 / 生成补丁 / 开 PR
├── store/
│   ├── publish.py           # 数字产品自动上架（Creem）
│   └── products/            # 生成的产品定义
├── .github/workflows/
│   └── radar.yml            # 定时挂机（每 3 小时）
├── docs/
│   ├── 傻瓜级部署教程.md      # 从零到挂机，约 40 分钟
│   ├── 收款通道可行性.md      # 各平台实测对比 + 开户清单
│   └── GitHub权限授予指南.md  # 读写权限怎么开
└── reports/                 # 扫描报告（自动生成）
```

## 三分钟跑起来

```bash
cd github-earning
python3 radar/scan.py          # 扫描（约 2 分钟）
python3 radar/hunter.py --scan # 看可认领目标
python3 store/publish.py       # 生成产品定义（演练模式，不真实上架）
```

无任何第三方依赖，只用 Python 标准库。

## 评分逻辑

```
score = 金额(≤30) + 竞争度(≤25/-30) + 仓库可信度(≤25/-30)
      + 需求真实性(≤20) + 结算可行性(+10/-12) + 自动适配度(≤25)
```

- **自动适配度**：识别 Ubiquity 的 `Time: <N Minutes` 标签。15 分钟内=极优，
  单次挂机运行就能完成并提交 PR。
- **结算可行性**：对照 `PAYOUT_RAILS` 表判断大陆个人能否实际收到钱。

## 重要提醒

- 挂机系统解决的是**信息与流程**，不解决**需求与信任**。收入取决于你的选题与内容投入。
- 一切外部动作默认走 `outbox/` 人工核对。真正的"全自动无人值守"会因信誉问题被反噬。
- 涉及加密货币结算的通道在大陆有合规风险，本项目不推荐。
- 平台条款普遍禁止信息拼凑绕过 KYC，请走正规路径。
